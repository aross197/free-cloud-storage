# Free Cloud Storage Guide

A clean, mobile-friendly static website that lists the best free cloud storage options for Android and iOS (2026), explains why you cannot host real cloud storage on GitHub Pages, and shows how to publish this site itself for free.

## Live demo

After you enable GitHub Pages, the site will be available at:

`https://aross197.github.io/free-cloud-storage/`

## How to publish on GitHub Pages

1. Go to the repository **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder → Save.
4. Wait a minute or two. Your site will be live.

No build step or Node.js required.

## What’s included

- Comparison table of free tiers (MEGA, Google Drive, OneDrive, iCloud, Proton Drive, etc.)
- Direct links to official Android and iOS apps
- Clear explanation of GitHub Pages limitations
- Step-by-step instructions to host this page
- Notes on using GitHub repos as personal storage
