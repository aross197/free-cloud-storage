GitHub Pages Limit

GitHub Pages is static only. No backend, no permanent user uploads, no real cloud storage service.

You cannot run a public Dropbox-style service from GitHub Pages. For personal use only, some people treat their own GitHub repos as a drive via the API (limits: ~1 GB/repo, 25 MB typical upload, 100 MB hard file limit).

Host This Page

  1. Create public repo
  2. Upload index.html
  3. Settings → Pages → Deploy from branch → main / root
  4. Live at username.github.io/repo

Tips

  • Enable camera upload in the apps
  • Stack multiple free accounts if needed
  • Prefer ZK services (MEGA, Proton) for privacy
  • Keep important files in more than one place
